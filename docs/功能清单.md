### 2.3 根组件 — `src/App.tsx`（357 行）⬜
- **作用**：布局总装 + 全局快捷键 + 自动保存链路 + 面板编排，全部横切能力交汇点。

  - 最近访问：`recentViews`（localStorage，MAX 50）。
  - 快捷键：搜索 / 保存 / 撤销重做 / 新建文档 / 侧栏折叠（Ctrl+\，注释说明 Ctrl+B 与加粗冲突改键）/ 收藏；Escape 按优先级依次关面板。

- **问题**：357 行承担快捷键注册表 + 面板编排 + 保存接线三职责，继续增长应拆数据驱动快捷键表。

## 4. 状态管理与数据模型层

### 4.1 store 组装与工具 ⬜
- `src/store/index.ts`：9 slice 经 immer 合并单一 `useNotesStore`；`selectActiveDoc` 直读缓存字段。
- `src/store/storeUtils.ts`：`newId()`（crypto.randomUUID 带回退）、`generateShareUrl`（file:// 下相对路径兜底）。
- `src/store/types.ts`：9 切片交叉类型总线。

### 4.2 coreSlice（565 行，最核心）⬜
- **state**：`notebooks`/`trash`/`saveStatus`/`lastSavedAt`/`loadFailed`/`lastMutationAt`/`activeNotebookId`/`activeDocId`/`activeDoc`(缓存)/`searchText`。
- **24 个 action**：持久化 4 / 文档库 3 / 文档 8 / 回收站 4 / 导航搜索 3。
- **自动版本快照**（`pushAutoVersion`，唯一写入方）：仅 content/title/tags 变更触发；**30s 合并窗口**；上限 50，>100KB 大文档降为 5；按 docId 裁剪。
- **健壮性四重保护**：
  1. `loadNotes` 失败置 `loadFailed`，`saveNotes` 拒绝保存（防空数据覆盖）；
  2. 保存失败 `trimAllVersions(notebooks, 10)` 瘦身重试（应对 50MB IPC 上限）；
  3. `updateDoc` parentId **成环防御**（while + seen 集合回退 null）；
  4. `restoreFromTrash` 多级降级（无源库→回退第一个库；无任何库→新建「已恢复文档」库；父文档不存在→挂根）；`detachAndReparent` 子文档重挂。
- **优化点**：565 行偏大，回收站逻辑可拆独立 slice。

### 4.3 versionSlice ⬜
- `getDocVersions` / `restoreVersion`（恢复前先把当前内容备份为 `type:'manual'`、`versionTag:'恢复前备份'`，再 slice(0,50)）。严格遵守「自动快照只 coreSlice 一个 writer」。

### 4.4 shareSlice 🟡
- `generateShareLink`（4 档权限、密码、有效期）/ `deleteShareLink`（按剩余链接数回写 settings.enabled）。
- **问题：store 层 import 组件层 `toast`**（分层瑕疵，单测需 mock toast）。优化：返回 `{ok,error}` 信封由调用方弹 toast（与 AI 层约定一致）。

### 4.5 commentSlice ⬜
- `addComment`（author 硬编码「我」）/ `deleteComment` / `addReply`。单层回复，无楼中楼。

### 4.6 tagSlice ⬜
- 12 个 action：CRUD（`deleteTag` 级联清除文档引用、usageCount 防负数）+ 统计（`getTagStats` 分布 ≥10/3–9/1–2/0；`getRecommendedTags` 词匹配评分 limit 5）+ 批量/层级（`getTagsWithHierarchy` Map 建树）。
- **优化点**：取数函数以 action 挂 store，宜改 selector。

### 4.7 searchSlice ⬜
- `search(query, filter?)`：支持 `-排除词`/`"精确短语"` 语法；日期过滤（结束日补 23:59:59）；`getSnippet` 前后 radius 40 字；结果倒序 limit 50。
- `getSearchSuggestions`（标签+标题+历史三路，limit 8）；历史 5 操作（去重、上限 20、置顶）。
- `tokenizeChinese`（中文单字分词）；`searchTextCache` WeakMap 增量缓存（updatedAt 失效）。
- **问题**：`SearchFilter.author` 类型声明未消费；无相对时间（最近 7 天）快捷项；搜索语法/日期过滤/snippet 均无测试。

### 4.8 undoRedoSlice ⬜
- 按 docId 隔离快照栈（past/future，上限 200）。7 例单测全覆盖。

### 4.9 quickNoteSlice ⬜
- 5 action；每个写操作**同步 saveQuickNotes()** 落盘（localStorage `notes-quick-notes`）。无防抖（每次按键级编辑写盘，量小可接受）。

### 4.10 keyboardSlice ⬜
- **37 条默认快捷键**（通用 7 + 编辑 30）；自定义键 localStorage `notes-custom-shortcuts`；Ctrl+K 被搜索占用故插链接定 Ctrl+Shift+L。无专门测试。
