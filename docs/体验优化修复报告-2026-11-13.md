## 二、数据安全修复（P0/P1，用户内容不再丢）

1. **小记数据丢失链**（lead）：启动合并顺序颠倒会用磁盘旧副本冲掉本机较新小记并落盘；800ms 防抖窗口内切视图/崩溃丢编辑；删除后被备份"复活"。
   → 立即落盘 + 先本机后磁盘合并 + 删除墓碑（90 天 TTL）。回归 `quickNotePersistence.test.ts` 11 用例。
2. **加载失败永久失去出口**（lead）：「稍后处理」销毁唯一恢复弹窗后，新编辑全部不落盘、重试按钮是死的。
   → 最小化为常驻横幅 + SaveIndicator「去处理」入口 + 保存拦截明确提示 + Esc 让位确认框。回归 `loadFailureRecovery.test.tsx` 6 用例。
3. **重启丢全部标签**（search）：启动 prune 早于数据加载，把恢复的标签清空并写回 localStorage。
   → prune 加「未加载完成跳过」闸门 + loadNotes 成功后补调；删除/移动文档 4 条路径 store 内闭环清理。
4. **标签页关闭激活错**（search）：在删除后的列表里找被删项恒 -1，关中间标签跳最右。→ 接收原列表求 index。
5. **备份恢复谎报成功**（ui）：恢复后重载失败仍弹「已恢复」。→ 按 loadFailed 分支提示。

## 三、编辑器修复（P1×4 + P2×5，audit-editor）

1. **列表/引用/代码块选区偏移错位**：给第二项加粗落到第一项。→ domOffset 重写为按行映射（li↔源码行、行首标记计入、嵌套取最深匹配），33 用例 + 真机断言。
2. **键盘 Ctrl+Y 静默无效**：全局撤销绕过 forceRender。→ store `undoRedoSeq` 序号驱动重建，覆盖所有入口。
3. **拼音回车被打断**：全仓库无 IME 守卫。→ keydown(isComposing/229) + input 双守卫，compositionend 补跑；两内核都加。
4. **斜杠菜单残留劫持 Enter**：点别处不关菜单，回车在旧位置插命令。→ selectionchange 同步 cursor 语义。
5. 格式刷多格式互相覆盖 → 同一份演进源码串行折叠一次回写（附带修复富文本下复制不到格式）。
6. 粘贴 HTML/图片不替换选区 → 删除 [start,end) 再拼接。
7. Ctrl+Shift+V / Ctrl+Alt+C / Ctrl+Enter 静默失效 → 置位-消费机制 + 整块插行。
8. 空引用块致 data-md 整体错位 → blockquote/callout 排除出空块判定。
9. 查找栏关闭后焦点丢失 → onFocusEditor 双内核回调。

## 四、AI 修复（P1×3 + P2×4，audit-ai + lead）

1. **划词 AI 默认内核下完全失效**（lead 钩子双内核 + editor 接线）：textareaRef 恒 null 直接 return。→ 结构化端口 getSelectionRange/selectRange，无选区 toast，快照失配降级。9 用例。
2. **设置页单字段编辑重置其余配置**（含 consent 授权丢失）：草稿空基底取 EMPTY_FORM。→ 取当前展示态；全字段回归。
3. **推理模型流式必超时**：计时器只认正文 delta，思维链超 20s 被误杀。→ 任何 data 帧（含 reasoning_content）重置计时；超时文案按实际段。
4. 缓存键漏 baseUrl（换服务商命中旧结果）→ 归一化 baseUrl 入键。
5. MiMo→其它预设残留 max_completion_tokens → 恒返回 maxTokensParam。
6. **非流式取消/超时契约**（lead 渲染侧 + ai 主进程）：signal/timeoutMs 曾被静默丢弃。→ 渲染侧立即结算 + 主进程 activeNonStream 登记，退避期取消 race（含 batch 逐项）。41+4 用例。
7. 配置类错误无出路 → 「去设置」按钮深链 AI 页签（NOT_CONFIGURED/AUTH/FORBIDDEN/NOT_FOUND）。
8. AI 设置 Esc/遮罩丢草稿 → aiSettingsDirty 守卫（Esc 链 + ×/遮罩同语义）；清除密钥 danger 确认。
9. 防御加固：日志脱敏补 `tp-` 前缀（MiMo key）。

## 五、搜索导航修复（P1×2 + P2×6，audit-search）

1. **开始页点搜索结果毫无反应**：只改 active id 不切视图。→ 统一走 requestDocOpen 通道（最近浏览/视图切换随之修复）。
2. 重启丢标签（见数据安全 3）。
3. 置顶历史 Enter 搜错词 / 建议分组下标乱序 → store 排序单一来源 + 建议输出顺序对齐渲染。
4. 虚拟化文档树（>200 篇）方向键焦点消失 → VirtualScroll 命令式 scrollToIndex。
5. 一次 Esc 关两层面板 → 面板自关 stopPropagation。
6. 非手动排序拖拽假成功 → dragOver/drop 双闸门禁用同级落点。
7. 收藏视图点文档跳走 → 本地打开不切视图；**最近浏览记录下沉共享服务**（lead，修复不切视图后不记最近的回归）。
8. QuickOpen 打开后焦点落 body → subscribeDocOpen 通道 rAF 聚焦（仅该通道，不抢输入焦点）。

## 六、界面交互修复（P1×6 + P2×8，audit-ui + lead）

1. **标签视图全屏遮罩锁死**（× 是死按钮）→ embedded 模式无遮罩，弹窗模式保留 dialog 语义。
2. 加载失败出口（见数据安全 2）。
3. **chunk 加载失败炸全应用** → LazyLoader 局部错误边界；React.lazy 缓存 rejection，重试一次无效即引导整页重载。
4. **子弹窗 Esc 关错层丢草稿** → VersionTag/CustomTemplate/TagEdit 统一 capture 只关自己。
5. **评论删除无确认**（含整条回复串）→ danger 确认。
6. **版本对比反直觉**（点列表被弹回/右侧空白）→ 对比模式不退出 + 三种引导空态 + 「设为对比基准」语义。
7. 死复选框「显示所有本地存储版本」→ 受控过滤（仅手动版本）+ 徽标按完整列表计算。
8. **自定义快捷键不可达**（lead）：updateShortcut/resetShortcuts 无调用方。→ ShortcutsTab 录制 UI（capture 拦截、冲突检测、Esc 取消、单项/全部恢复）；硬编码键位标 fixed 不给录制入口（避免新死设置）。8 用例。
9. 空库侧栏 +/Ctrl+N 死按钮 → resolveTargetNotebookId 公共 util（三入口统一）。
10. AI 设置草稿守卫（见 AI 8）。
11. 分享空格密码/删除无确认 → passwordEnabled 布尔态 + 原样传值 + danger 确认。
12. 演示模式 Ctrl+Alt+←→ 双触发换文档 → 修饰键守卫 + capture 拦截已处理键。
13. 焦点陷阱补齐（Share/ShortcutHelp/Version/Tag 弹窗）+ Esc 链补 comments/outline。
14. 版本导出 blob 下载无提示 → 走 IPC exportDoc + 成功/失败 toast。
15. 小记面板（lead）：删除确认、空内容保存禁用+提示、标签可编辑、不再截断前 8 个。
16. VersionTagModal 空名「确定」静默无效 → 禁用+title（lead）。
17. **主题菜单项切完不关菜单**（lead，E2E 暴露）：`onClick={toggleTheme}` 漏了 `setShowMoreMenu(false)`，其它菜单项都有。表现为切主题后菜单还开着，再点「更多」反而把它关掉——用户以为按钮失灵。→ 补齐关闭调用。
18. **下拉菜单触发按钮状态竞态**（lead，E2E 暴露）：`useEditorHeaderMenus` 用 mousedown 做外部关闭，早于按钮自身 onClick，同一事件里「先关再取反」会把状态算反。→ 触发按钮加 `data-eh-menu-trigger`，监听里跳过它们，切换语义由 onClick 独占。
