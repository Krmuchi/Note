# 工具-大文件切片与回滚连坐

## 触发条件
要"重排/抽取大文件的一段函数"，或修复后想 `git checkout` 回滚某个文件。

## 首选姿势
- 一次只抽**边界明确、区间内不含其它声明**的几个函数；切完立刻 `npx tsc -b --noEmit`。
- 动手前 `git diff --stat` 记下该文件还有哪些未提交改动——`git checkout <file>` 会把同文件里的功能修复一起回滚（连坐）。
- 大文件修改优先 edit 单行锚点 / 小段替换，不做按行号切片写回。

## 反面清单
- `Get-Content` + 按行号切片写回（RichEditor 曾误删 RichEditorProps / INPUT_RULES / CODE_LANGUAGES）。
- 未记 diff 就 checkout 回滚（功能修复连坐丢失）。

## 验证方式
切片后 tsc 零错误 + git diff 确认只动了目标区间。
